# 砂と ひと息

砂時計の内部で砂粒（円形パーティクル）が重力・壁・粒子同士の衝突によって
流れ落ちる様子を再現する、ブラウザ上で動く物理シミュレーションのプロトタイプです。

## 使い方

ビルド不要の素のHTML/CSS/JavaScriptです。`index.html` をブラウザで直接開くか、
簡易サーバーを立てて開いてください。

```bash
# 例: リポジトリ直下で
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

画面上の「砂のつぶ」で粒子数を指定し、「もういちど」で反映します。
砂時計をクリック・タップするか、「ひっくり返す」で上下を入れ替えられます。
砂時計にフォーカスして Enter / Space キーでも操作できます。
動きを減らす設定では回転アニメーションを省略します。

背景は、ディフューザーとリスのぬいぐるみの参照写真をもとにした水彩風イラストです。
生成プロンプトは [assets/README.md](assets/README.md) に記録しています。

## 粒子数の目安について

実装前に、このPC（WSL2環境）のスペックを確認した上で適切な粒子数を検討しました。

- CPU: AMD Ryzen 7 5800H（8コア16スレッド）
- メモリ: 実機28.9GB（WSL2側の割り当ては14GB）
- GPU: AMD Radeon Graphics（統合、専用GPUメモリ3.0GB + 共有14.5GB）

今回はCanvas2D + CPU上での物理演算という構成のため、GPUの性能は使わず
シングルスレッドJavaScriptでの処理速度が上限を決めます。

素朴な総当たり（全粒子ペアをチェックするN²アルゴリズム）では数百粒子が限界ですが、
このプロトタイプでは**空間分割グリッド**（セルサイズ ≈ 粒子直径の2.2倍）を使い、
近傍セルの粒子同士のみを衝突判定することで、以下を目安にしています。

- **推奨値: 2,000〜3,000粒子**（60fps付近を維持しやすい）
- スライダーは200〜5,000の範囲で調整可能。5,000粒子まで上げた場合の
  実機でのfps低下具合を見て、快適な上限を確認できるようにしています

## 物理モデルの概要

### 形状

砂時計はコサイン曲線を使った、上下・左右対称の丸い輪郭で表現しています。
描画と壁との衝突判定には同じ境界関数を使います。
高さ（y座標）を与えると、その高さでの内壁の左端/右端のx座標を返す
`leftBoundAt(y)` / `rightBoundAt(y)` を用意し、これを壁との衝突判定に使っています。

### 壁との衝突

各粒子について、`containParticle()` でその粒子のy座標における左右の内壁位置に
座標をクランプする方式を採用しています。ネック部分は一定幅の通路として扱われ、
砂が自然にくびれを通って下に落ちる流量制御になります。厳密なポリゴン衝突より
シンプルですが、砂時計のように「高さごとに幅が決まる」形状とは相性がよく、
壁のすり抜け（トンネリング）が原理的に起こりません。

また、壁に接触している間は反発処理に加えて、壁沿い方向の速度を減衰させる摩擦
（`WALL_FRICTION_PER_SECOND`）を適用しています。「1秒間接触し続けたら速度が
何割残るか」という形で強さを指定しており、1サブステップにつき1回だけ適用する
ことで、フレームレートやサブステップ数に依存せず一定の強さになるようにしています。

### 粒子同士の衝突と運動量の吸収

各フレームを4回のサブステップに分割し、サブステップごとに以下を実行しています。

1. 休止中でない粒子について重力を加算し、位置を更新
2. 壁との衝突処理（クランプ）
3. 空間分割グリッドを再構築
4. 近傍セル（3x3）内の粒子ペアのみ距離判定し、めり込み分を押し戻し + 反発・摩擦の
   速度補正を実施（2回のイテレーションで安定化）
5. 壁との衝突処理を再度実施

粒子同士がぶつかったとき、相対速度が小さい（ほぼ静止接触に近い）場合は反発させず
運動量をそのまま吸収して止める閾値処理（`REST_VELOCITY_THRESHOLD`）を入れています。
反発係数を掛けて跳ね返すのは、ある程度速い衝突（例: 落下中の粒子が山に飛び込む瞬間）
だけです。

さらに、一定時間（`SLEEP_TIME_REQUIRED`）ほぼ静止し続けた粒子は「休止」状態にし、
重力の適用や自発的な移動を止めます。休止中の粒子は周囲からの衝突を引き続き受けますが、
弱い接触では動かさず、`WAKE_VELOCITY_THRESHOLD` を超える強い衝撃を受けたときだけ
目を覚まして通常どおり動き出します。これがないと、下から支える粒子の反力が積み重なった
粒子の上部まで伝わりきらず、山全体がいつまでも微振動し続けてしまいます（反復回数の
少ない接触解決ソルバーに共通する問題です）。休止機構により、砂が落ち切ったあとは
完全に静止し、反転操作などで実際に力が加わったときだけ自然に動き出すようになっています。

### 粒子サイズの動的スケーリング

要求された粒子数に応じて粒子の半径を自動調整しています
（基準: 2,000粒子で半径3.2px、`半径 ∝ 1/√粒子数`）。これにより、
スライダーで粒子数をどの値に設定しても上球にきちんと収まり、
かつ見た目の「砂の量」がおおよそ一定に保たれます。
